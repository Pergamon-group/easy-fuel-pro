# TDD First

Always follow Test-Driven Development (TDD). Before implementing or fixing any code, you must:
1. Write the tests for the expected behavior first.
2. Run the tests to see them fail (Red).
3. Implement the minimal code necessary to make the tests pass (Green).
4. Refactor the code while keeping the tests passing (Refactor).

Never write implementation code before writing the tests that define its expected behavior.
