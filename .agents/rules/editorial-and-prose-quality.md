# Editorial & Prose Quality (The Rubric)

- **Zero Em-Dashes**: Never use em-dashes (`—` or `–`) anywhere in prose, headings, alt texts, or code comments. Use commas, colons, parentheses, or periods.
- **Complete Interrogatives**: Never write sentence fragments for questions.
  - Correct: *"Are you looking for.....?"*
  - Incorrect: *"Looking for...?"*
